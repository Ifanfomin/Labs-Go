# Labs-Go
Всё описанное ниже ориентировано только как возможность быстро вспомниьт материал или на случай, если не хватает времени на полное прочтение оригинального курса.

Тут лежит курс по веб-проге по главам и урокам.  
Собрал .md файлы по каждому уроку.  
Просто кидаете этот файл или его содержимое любой LLM и она автоматом дает основную выжимку урока, ответы на квиз, и она же знает весь код из урока и т.д.

В каждом .md файле лежит:

- небольшая инструкция для нейроки, чтобы не писать промпт каждый раз.
- весь урок со вставками кода.
- весь квиз.
